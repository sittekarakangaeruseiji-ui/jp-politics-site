日本 政治 何が起きてる?

ニュースで政治の話を聞いても、その政策が何なのか、関わる人が何をしているのかを一から調べるのは大変です。 このチャンネルは、その調べものをお手伝いするために、日本の政治の「何が起きたのか」「なぜそうなったのか」「何が変わるのか」を、国会や政府の公式の資料(一次資料)をもとに整理してお伝えしています。

動画の投稿に使っているツールについて / About our upload tool

このチャンネルでは、自分たちで作った解説動画を自分たちのチャンネルに投稿するために、YouTube API サービス(YouTube Data API)を使う社内ツールを使っています。 ツールは一般には公開・配布しておらず、チャンネルの運営者だけが使います。ツールが行うのは、動画のアップロードと、アップロードした動画のタイトル・説明欄・タグの更新だけです。

We use an internal tool that uses YouTube API Services (YouTube Data API) to upload videos we produce to our own channel, and to update the title, description and tags of those videos. The tool is not public or distributed, and is used only by the channel operator.
