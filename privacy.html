プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-06

このポリシーは、YouTube チャンネル「日本 政治 何が起きてる?」の運営者(以下「運営者」)が使う動画投稿用の社内ツール(以下「本ツール」)での、情報の扱いを説明するものです。

This policy explains how the internal upload tool ("the Tool") used by the operator of the YouTube channel "日本 政治 何が起きてる?" ("the Operator") handles information.

1. YouTube API サービスの利用 / Use of YouTube API Services

本ツールは YouTube API サービスを使います。本ツールを使う人は、YouTube 利用規約に同意したものとみなされます。 Google による情報の扱いは、Google プライバシーポリシーをご覧ください。

The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

2. 利用者 / Users

本ツールを使うのは運営者だけです。一般の方に提供・配布しておらず、視聴者の情報を本ツールで集めることはありません。

The Tool is used only by the Operator. It is not offered or distributed to the public, and it does not collect any information about viewers.

3. 扱う情報 / Information accessed and used

  • 運営者が Google アカウントで許可した、運営者自身の YouTube チャンネルへのアクセス権(OAuth 2.0 の許可)
  • 運営者がアップロードする動画ファイルと、そのタイトル・説明欄・タグ
  • アップロードした動画の ID と公開範囲(結果の確認と記録のため)

The Tool accesses only: the authorization (OAuth 2.0) that the Operator grants for the Operator's own YouTube channel; the video files the Operator uploads and their titles, descriptions and tags; and the video IDs and privacy status of uploaded videos (to confirm and record results).

4. 利用目的 / How information is used

運営者が制作した動画を運営者のチャンネルにアップロードし、そのタイトル・説明欄・タグを更新するためだけに使います。広告、分析、販売、そのほかの目的には使いません。

The information is used solely to upload videos produced by the Operator to the Operator's own channel and to update their titles, descriptions and tags. It is not used for advertising, analytics, sale or any other purpose.

5. 保存 / Storage

許可でもらった鍵(リフレッシュトークン)は、運営者のパソコンの中だけに保存し、外部のサーバーには送りません。アップロードした動画の ID などの記録は、運営者の非公開の作業記録に残します。

The refresh token obtained through authorization is stored only on the Operator's own computer and is not sent to any external server. Records such as uploaded video IDs are kept in the Operator's private work records.

6. 第三者への提供 / Sharing

本ツールで扱う情報を、第三者に提供・販売することはありません(YouTube API サービスへの送信を除きます)。

Information handled by the Tool is not shared with or sold to any third party, other than being sent to YouTube API Services.

7. 削除と許可の取り消し / Deletion and revoking access

運営者は、パソコンに保存した鍵を削除することで、いつでも本ツールの利用をやめられます。また、Google アカウントのセキュリティ設定(アカウントへのアクセス権の管理)から、本ツールへの許可をいつでも取り消せます。保存したデータの削除の依頼は、下の連絡先で受け付けます。

The Operator can stop using the Tool at any time by deleting the stored token, and can revoke the Tool's access at any time via the Google security settings page. Requests to delete stored data can be sent to the contact below.

8. 変更 / Changes

このポリシーを変更するときは、このページを更新し、最終更新日を改めます。

If this policy changes, this page and its "Last updated" date will be updated.
